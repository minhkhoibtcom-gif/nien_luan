# Dataset cũ (không còn dùng)

Phiên bản đầu của đồ án dùng bộ dữ liệu "Online Food Delivery" (Ấn Độ, 388 dòng) được mở rộng lên 3000 mẫu
bằng `generate_dataset.py`. Từ tháng 11/2026 hệ thống chuyển sang dataset Gen Z Việt Nam
(`data/genz_vn.xlsx`, 361 người) theo yêu cầu dùng dữ liệu Việt Nam, nên hai file này chỉ giữ lại để tham khảo.
